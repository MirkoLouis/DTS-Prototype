--- 1.6 Scope and Delimitation (2nd paragraph) ------------------------

FIND:
Technical implementation is restricted to the PHP programming language; specifically, the prototype is built using the Laravel 12 framework to provide a modern, optimized structure while adhering to the client's language constraints. Additionally, the system utilizes MySQL as the relational database engine, selected for its native support for row-level locking — a critical requirement for resolving concurrent transaction conflicts — its proven compatibility with the Laravel Eloquent ORM, and the researchers' demonstrable proficiency in MySQL database architecture and optimization, which ensures that the implementation is both technically sound and efficiently executed (Silberschatz et al., 2020).

REPLACE WITH:
Technical implementation is restricted to the PHP programming language. Following the recommendation of the DepEd Iligan ICT head, the prototype is implemented in framework-free PHP 8.3 using PDO, so that the division's IT staff can maintain it without framework-specific knowledge; an earlier Laravel 12 build is retained only as a reference implementation. The system utilizes MySQL 8 (InnoDB) as the relational database engine, selected for its transactional row-level locking, which the system combines with optimistic version checking to resolve concurrent transaction conflicts (see M5), and for the researchers' demonstrable proficiency in MySQL database architecture and optimization (Silberschatz et al., 2020).

--- Chapter 4 / 5 (new paragraph to add) ------------------------------

ADD:
Scope revision: TF-IDF route prediction. The originally proposed TF-IDF route prediction was removed after data gathering. Keyword prediction would only apply to documents filed under the "Others" purpose, since official purposes already have a fixed route. Guests' free-text descriptions for these documents were overwhelmingly generic (e.g., "FOR APPROVAL", "FOR SIGNATURE"). Because such terms occur in nearly every "Others" submission, their inverse document frequency approaches zero, so they carry no routing signal. Documents with the same generic purpose were also routed to different departments. Routing of "Others" documents was therefore assigned entirely to the Records Officer, and official purposes use the route last finalized for that purpose.
